# Passive And Academy Node Icon Manual Handoff

## Generator Summary

- Source CSV: `docs/data/passive_and_academy_icon_prompts_v1.csv`
- Output path: `apps/web/public/assets/icons/nodes/{icon_key}.png`
- Render settings: `model=gpt-image-1.5`, `size=1024x1024`, `background=transparent`, `quality=medium`
- The prompts below are copied from the CSV prompt column and should not be modified.
- The Node generator in `tools/generate_node_icons.mjs` validates `icon_key`, reads `.env`, writes `.png` outputs plus matching `.txt` prompt sidecars, tracks resumable state in `tools/.cache/node_icon_art_state.json`, writes the last run report to `tools/.cache/node_icon_art_last_run.json`, and only rebuilds a node icon manifest if one already exists.
- This CSV currently stores the final `prompt` column without CSV quoting, so the generator/parser preserves the full prompt by merging any extra trailing comma-separated values back into the `prompt` field.
